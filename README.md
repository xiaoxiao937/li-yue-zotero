# 狸阅 for Zotero

一次选择多篇 Zotero 文献，对每篇 PDF 独立执行同一个自定义 Prompt，并把每份 AI 回答分别保存到对应文献条目的子笔记中。

## 当前版本

这是 `0.8.2` Beta：

- 支持从条目右键菜单启动批量任务；
- 支持主界面工具栏按钮和“工具”菜单常驻入口；
- 任务窗口采用单实例；再次点击入口会恢复窗口并置于最前面；
- 使用蓝色侧脸狸花猫作为插件图标；工具栏保留原始造型并使用原生 24px 高对比资源；
- 支持普通条目和 PDF 附件混选、自动去重；
- 每个条目选择一个 PDF；
- 支持 OpenAI Responses API；
- 支持 DeepSeek 和自定义 OpenAI Chat Completions 兼容接口；
- 长 PDF 在单篇内部自动分块和合成；
- 显示预计请求、token、费用和耗时；
- 模型单价按美元录入，并通过可调整汇率统一显示人民币预计费用；
- 有限并发、取消、失败后单独重试；
- 提供稳健、均衡、高速和极速档位（并发 2/4/6/8）；
- 高并发遇到 API 限流时，所有工作线程共享退避时间并按响应头自动恢复；
- 空响应、限流和临时网络错误自动重试，并显示重试次数；
- 即使 API 已返回部分文字，也会检查结束状态；输出被截断时自动扩大上限重试，未完整结束不会创建笔记；
- 使用 DeepSeek V4 Flash/Pro 批量阅读时自动关闭隐藏思考，避免思考过程耗尽输出额度而没有最终正文；显式选择 reasoner 模型时保留思考，并允许重试扩容至 64K；
- 任务结束后显示逐篇运行报告，并发送可点击的系统通知；点击通知会前置仍在运行的狸阅窗口并定位到最新报告，窗口已关闭时会重新打开，系统通知不可用时自动使用 Zotero 通知；
- 批处理期间阻止电脑自动休眠，但允许屏幕正常关闭；完成、取消、异常或窗口退出后自动释放；
- 异常退出后可恢复未完成任务，并通过已有笔记指纹避免重复处理成功项；
- 保留最近 20 次任务报告，准确区分成功、失败、跳过、PDF 异常、取消和未处理，可一键重试失败/未处理项；
- Prompt 区域可一键加载最近一次实际执行任务所用的 Prompt；
- API 设置和历史报告使用独立遮罩浮层，任务报告优先展示异常并默认折叠成功项；
- 历史报告的“查看”会在历史浮层内进入独立详情层，可返回报告列表，不再跳转到主页面底部；
- 插件脚本和样式使用版本指纹避免 Zotero 更新后继续加载旧资源；状态文件保留备份并兼容后续数据结构迁移；
- 相同 Prompt 与相同 PDF 已生成过笔记时默认跳过，可手工勾选强制重做；
- 每篇成功后立即创建自己的子笔记；
- API Key 保存在系统登录凭据中。

## 安装

1. 使用 `./build.sh` 生成 XPI，或直接使用发布产物 `li-yue-0.8.2.xpi`。
2. 打开 Zotero → 工具 → 插件。
3. 点击齿轮菜单 → Install Plugin From File…。
4. 选择 XPI 文件。
5. 点击工具栏的小猫，或选择文献后右键选择“狸阅：批量独立阅读…”。无需预先选择文献；空白启动时会自动打开“添加文献”选择器。

狸阅窗口中的“添加文献”会打开资料库选择器：左侧浏览 Zotero 资料库和文件夹，右侧搜索并多选带 PDF 的文献，确认后追加到当前批次并自动去重。“替换列表”会用 Zotero 主界面当前选中的文献替换整个列表；“重检 PDF”只重新检查当前列表的 PDF 文本和 OCR 状态，不改变列表。

如果点击小猫时 Zotero 主界面没有选中文献，狸阅仍会正常打开，并自动进入“添加文献”。若检测到未完成任务或准备草稿，则优先显示恢复入口，避免覆盖已有进度。

资料库选择器默认展开“我的文库”一级，其他层级收起，可用标准箭头逐层展开或收起文件夹。重检和替换期间，窗口左下角会持续显示当前进度，完成结果会保留显示。

准备任务时，只要列表中至少有一篇文献，狸阅就会自动保存文献列表、Prompt、文献勾选状态和每个条目所选的 PDF。零文献状态不会保存或提示草稿。窗口关闭、Zotero 重启或插件升级后，可选择继续或放弃上次草稿。草稿与执行中断恢复分别保存，API Key 始终只保存在系统登录凭据中，不会写入草稿。

建议先在单独的 Zotero 测试资料库中验证。插件会向用户指定的 API 服务发送 PDF 提取文本并创建 Zotero 子笔记。

## 自动更新

从 v0.9.18 起，狸阅通过公开 GitHub 仓库中的标准 Zotero JSON 更新清单检查新版。首次安装 v0.9.18 仍需手工导入；以后发布到 `xiaoxiao937/li-yue-zotero` 的新版本可由 Zotero 自动发现。更新仅替换插件代码，不会删除本机 API 设置、草稿、恢复任务或历史报告。

`./build.sh` 会同时生成 XPI 和 `update.json`。发布时将 XPI 放到 `dist/li-yue-<version>.xpi`，并将同次生成的 `update.json` 放到仓库根目录。可用以下命令检查本地或公开更新渠道：

```sh
python3 scripts/verify_update_manifest.py update.json
python3 scripts/verify_update_manifest.py https://raw.githubusercontent.com/xiaoxiao937/li-yue-zotero/main/update.json --check-download
```

## API 设置

### OpenAI

- 服务商：`OpenAI`
- Base URL：`https://api.openai.com/v1`
- 模型：填写账户可调用的模型 ID
- 协议：Responses API

### DeepSeek

- 服务商：`DeepSeek`
- Base URL：`https://api.deepseek.com`
- 模型：填写账户可调用的模型 ID
- 协议：Chat Completions

API 设置中的模型为“下拉选择 + 手工输入”组合：输入 API Key 后点击“读取模型”，或执行“测试连接”，即可从当前账户的 `/models` 接口同步可用模型；仍保留手工模型 ID 以兼容特殊接口。

模型价格和汇率随时可能变化。界面的默认价格与美元兑人民币汇率只是初始参考；运行前请按照服务商最新价格和你希望采用的汇率手工校正。预计费用统一显示为人民币，最终账单以服务商为准。

本构建在 manifest 中声明支持 Zotero `9.0.0` 至 `10.99.99`，并按本机 Zotero `9.0.6` 的运行时源码核对了关键 API。

## 已知限制

- macOS 开启“台前调度”且狸阅被放在另一个窗口组时，再次点击工具栏小猫可能只会提示该窗口组，而不会自动切换到前台；这是系统的窗口组切换限制。请从台前调度侧栏或“窗口”菜单手工切回狸阅。
- 仅处理 Zotero 已能提取全文的文本型 PDF；会识别疑似扫描件、极少文本和明显乱码，自动跳过且不调用 API，并在任务报告中标记“需要 OCR”。插件尚不执行 OCR。
- 一个条目一次只选择一个 PDF。
- 取消不会中止已经发出的 HTTP 请求，但会停止启动后续文献任务。
- 自定义兼容接口必须兼容 `POST /chat/completions`。
- UI 与 Zotero 运行时接口已做静态验证，但仍需要在目标 Zotero 版本中完成真实安装、API 和笔记写入测试。

## 开发验证

本项目无需 Node 构建步骤。Node 仅用于运行静态语法检查和纯逻辑测试：

```sh
node --check bootstrap.js
node --check content/main.js
node --check content/task.js
node tests/core.test.js
./build.sh
```

## 隐私

- PDF 提取文本、用户 Prompt 和模型回答仅发送到用户配置的 API 服务。
- 插件本身不包含中转服务器。
- API Key 不写入 Zotero 笔记或普通偏好设置。
- 为支持断点恢复和历史报告重试，Prompt 与任务状态会保存在本机 Zotero 数据目录的 `ai-batch-reader-state.json` 中；最近保留 20 次，不会发送到插件自有服务器。
- 状态写入使用 Zotero 的原子文件写入，并保留上一份有效内容为 `.bak` 备份；插件升级会迁移数据结构，不主动删除历史报告。
- 新生成笔记的标题以“🐱 狸阅”开头，并自动给父文献条目添加仅含“🎶”的简短标签；插件会在该资料库中将标签设为与图标一致的蓝色 `#5B8CFF`，但不会覆盖用户已经手工指定的颜色。这样可在 Zotero 条目树、标签列和标签筛选中直接辨认，重复处理不会产生重复标签。笔记记录回答、文献、PDF、模型、服务商、生成时间和插件版本。
- 笔记标题和正文均不显示 Prompt；插件只保存不可见的 Prompt 指纹，用于避免重复生成。
